구분하는 법

여러 곳에서 반복해 쓰이는 것(상품·글)은 ①, 특정 화면 한 자리에만 들어가는 사진·문구는 ②입니다.

01

브랜드 이름 표기

가장 헷갈리는 부분입니다. 자리마다 쓰는 형태가 조금씩 다릅니다.

어디에 넣나East oklmHITCHDumbpatches
상품 제목 앞East oklm,HITCHDumbpatches
공급업체East oklm,HITCHDumbpatches
컬렉션 이름East oklmHITCHDumbpatches
컬렉션 주소east-oklmhitchdumbpatches
블로그 글 태그East oklmHITCHDumbpatches

East oklm만 콤마가 붙습니다. 브랜드 로고 자체가 그런 형태라서 그렇습니다. 나머지 둘은 콤마가 없습니다.

세 가지만 기억하세요

띄어쓰기·철자정확히 맞춰야 합니다. East oklm ⭕ / Eastoklm ❌ / 뒤에 공백 ❌
대문자·소문자달라도 됩니다. HITCH = Hitch = hitch
콤마있어도 없어도 됩니다. 시스템이 알아서 맞춥니다
주의 ① — 태그에는 콤마를 넣을 수 없습니다

Shopify가 콤마를 “다음 태그” 구분 기호로 쓰기 때문입니다. 공급업체가 East oklm,이어도 태그는 East oklm으로 적으세요. 연결은 정상 작동합니다.

주의 ② — 컬렉션 주소는 자동 생성됩니다

이름을 East oklm으로 적으면 주소가 east-oklm이 됩니다. 다만 같은 이름이 이미 있으면 east-oklm-1처럼 숫자가 붙습니다. 저장 후 “검색 엔진 목록 편집”에서 확인하고 숫자를 지우세요.

가장 안전한 방법

이미 등록된 같은 브랜드 상품을 열어 공급업체 칸을 복사해 붙여넣기 하세요. 타이핑하지 않으면 틀릴 일이 없습니다.

02

상품 등록하기

가장 자주 하는 작업입니다. 관리자 → 상품 → 상품 추가

1

제목

East oklm, Logo Hoodie

브랜드, 상품명 형식으로 적으세요. 상품 페이지에서 콤마 뒤가 자동으로 줄바꿈됩니다.

2

설명

소재, 핏, 세탁 방법 등을 적습니다. 비워두면 상품 페이지에 설명 영역이 아예 안 나옵니다.

3

사진

준비한 사진을 끌어다 놓습니다. 첫 번째 사진이 목록의 대표 사진이 됩니다. 만드는 법은 03 사진 준비하기.

4

가격

숫자만 입력합니다. 예: 89000

5

공급업체 가장 중요

오른쪽 제품 구성 칸의 공급업체에 브랜드 이름을 적습니다.

East oklm,        HITCH        Dumbpatches
     ↑ 콤마 있음      ↑ 없음        ↑ 없음

여기가 틀리면 상품 페이지의 브랜드 링크와 아래쪽 JOURNEY 글 연결이 깨집니다.

6

사이즈

변형 칸 → 옵션 추가 → 옵션 이름 Size, 값 S M L

이걸 만들지 않으면 상품 페이지에 사이즈 선택 버튼이 안 나옵니다.

7

컬렉션

오른쪽 컬렉션 칸에서 브랜드 컬렉션 하나만 고릅니다. 전체 상품 목록에는 자동으로 들어갑니다.

8

게시 설정

상태 → 활성 · 판매 채널 → Online Store 체크

둘 중 하나라도 빠지면 화면에 안 보입니다. 상품이 안 보인다는 문제의 대부분이 이것입니다.

9

저장하고 확인

  • 브랜드 페이지에 상품이 보이는가
  • 홈 화면 PRODUCTS 줄에 보이는가
  • 상품을 눌렀을 때 사이즈 버튼이 나오는가
  • 브랜드 이름을 누르면 그 브랜드 목록으로 가는가

품절 처리하기

변형에서 해당 사이즈 선택 → 재고 추적 켜기 → 수량 0 → “재고 없을 때 계속 판매” 체크 해제

→ 상품 페이지에서 그 사이즈 버튼에 회색 빗금이 그어지고 선택이 안 됩니다.

03

사진 준비하기

픽셀 크기보다 비율이 중요합니다. 화면마다 사진이 잘리는 비율이 정해져 있고, 올린 사진은 그 비율에 맞춰 가운데를 기준으로 잘립니다.

3 : 2
메인 큰 사진2400 × 1600
16 : 9
블로그 대표1920 × 1080
3 : 2
ABOUT1200 × 800
5 : 6
브랜드 대표1200 × 1440
1 : 1
상품 사진1200 × 1200

↑ 도형은 실제 비율대로 그려져 있습니다. 크기는 최소값이며, 더 크게 올려도 화면에서 더 선명해지지는 않습니다.

상품 사진만 정사각형인 이유

같은 사진 한 장이 두 곳에서 다르게 잘립니다.

목록 · 홈 카드

세로로 길게 5 : 7 — 좌우가 잘림

상품 상세

가로로 넓게 27 : 20 — 위아래가 잘림

세로로 만들면 상세에서 위아래가 날아가고, 가로로 만들면 목록에서 좌우가 날아갑니다. 정사각형 + 가장자리 여백이면 어느 쪽으로 잘려도 상품이 안 잘립니다.

한 줄 요약

1200 × 1200 정사각형 · 상품을 가운데 · 사방에 10~15% 여백. 상품당 3~4장.

파일 규칙

  • 형식 JPG (투명 배경이 필요하면 PNG)
  • 용량 한 장 300~500KB 이하 — 너무 크면 사이트가 느려집니다

사진을 안 넣으면

빈 화면이 되지는 않습니다. 회색 상자가 대신 보입니다. 브랜드 대표 사진은 안 넣어도 컬렉션 사진이나 첫 상품 사진이 자동으로 들어갑니다.

04

Journey 글 쓰기

관리자 → 콘텐츠 → 블로그 게시물

칸어떻게 쓰나예시
제목브랜드 : 헤드라인East oklm, : ONLY ONE GARMENT
태그브랜드 이름 (콤마 없이)East oklm
대표 이미지목록과 상세의 배너 사진1920 × 1080 (16:9)
내용글 본문 (사진도 넣을 수 있음)

제목의 콜론(:) 앞부분이 화면에서 브랜드 이름으로 표시됩니다. 여기엔 콤마를 써도 됩니다.

태그를 꼭 넣으세요

블로그 글의 태그는 그 브랜드 상품 페이지에 이 글을 띄우는 역할을 합니다. East oklm 태그를 단 글은 East oklm 상품 페이지 아래에 자동으로 나타납니다.

브랜드글에 넣을 태그
East oklmEast oklm — 콤마 빼고
HITCHHITCH
DumbpatchesDumbpatches

그 외

  • 배너 위의 큰 문구는 고정값이라 글마다 입력할 필요 없습니다
  • 목록 순서는 발행일 순입니다
  • 요약(Excerpt) 칸은 쓰지 않으니 비워두세요
05

안 해도 되는 것

상품 태그비워두세요. 브랜드 연결은 공급업체가 전부 처리합니다
전체 상품 컬렉션에 넣기자동으로 들어갑니다
상품 요약, SEO 설명지금 화면에서 쓰지 않습니다
06

가끔 하는 일

컬렉션 만들기

관리자 → 상품 → 컬렉션 — 새 브랜드가 생겼을 때만 만듭니다.

  • 자동 — 조건을 공급업체 = 브랜드명으로 걸면 해당 상품이 알아서 담깁니다 (추천)
  • 수동 — 상품을 하나씩 골라 담습니다

컬렉션의 제목과 설명은 그 페이지 맨 위에 그대로 나옵니다.

메뉴 바꾸기

관리자 → 온라인 스토어 → 메뉴 → main-menu — 오른쪽으로 드래그하면 하위 항목이 됩니다.

SHOP
  ├ VIEW ALL          ← 전체 상품으로 연결
  ├ CLOTHING          ← 제목일 뿐, 클릭 대상 아님
  │   ├ East Oklm
  │   └ Hitch
  ├ LIFE STYLE
  │   └ Mesh Coffee
  └ ACC
      └ Dumbpatches

CLOTHING 같은 그룹 제목도 Shopify 규칙상 링크를 비울 수 없습니다. #을 넣어두면 됩니다.

상단 바 바꾸기

온라인 스토어 → 테마 → ⋯ → 사용자 지정 → 헤더 → 아래 Shipping bar item 블록들

맨 위 회색 줄(Worldwide Shipping 등)입니다. 항목 하나가 블록 하나입니다.

하고 싶은 것방법
문구 고치기블록 클릭 → Text. 입력한 대소문자 그대로 나옵니다
아이콘 바꾸기Icon 목록에서 선택 — Plane(비행기) · Parcel(상자) · Location pin(위치) · Truck · Return arrow · Lock · Gift · Globe · Check · Star · No icon(아이콘 없음)
누르면 이동하게Link에 주소 입력 (비우면 클릭 안 됨)
항목 추가블록 추가 → Shipping bar item (최대 4개)
순서 바꾸기블록을 드래그

  • 문구는 짧게 쓰세요. 4개일 때 너무 길면 끝이 …으로 잘립니다.

07

문제 해결

증상확인할 것
상품이 화면에 안 보여요상태가 활성인지, 판매 채널에 Online Store가 체크됐는지
사이즈 버튼이 안 나와요옵션 이름이 Size인지
브랜드 이름을 눌러도 안 넘어가요공급업체 철자가 다른 상품과 같은지
상품 페이지 아래 글이 엉뚱해요블로그 글의 태그가 그 브랜드 이름인지
설명·사진 영역이 비어 보여요해당 칸이 비어 있으면 영역 자체가 사라집니다
상단 바가 안 보여요헤더의 Show shipping bar가 켜져 있는지, Shipping bar item 블록의 Text가 비어 있지 않은지
바꿨는데 그대로예요강력 새로고침 — Mac Cmd+Shift+R / Windows Ctrl+Shift+R
